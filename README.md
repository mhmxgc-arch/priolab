# Priolab — ניתוח רווח והפסד

ממשק דפדפן בעברית להצגת דוחות רווח והפסד בפורמט Excel, ניתוח דוח בודד והשוואת שני דוחות.

## יכולות

- טעינת קובץ `.xlsx` במבנה העמודות: `כותרת;`, `סעיף רווח והפסד`, `חשבון`, `תאור חשבון`, `סכום`, `מטבע`.
- שיוך תיאור דוח, שנת מס, חודש התחלה וחודש סיום לכל קובץ. כמה דוחות של אותה שנת מס יכולים להתקיים בתקופות שונות.
- גרפים להכנסות, עלויות, הוצאות מימון והוצאות הנהלה וכלליות; השוואת דוחות לפי בחירה.
- אזהרה כאשר התקופות אינן בנות השוואה. השוואת הרווח מתבססת על רווח לפני מס כאשר סעיף המס חסר באחד הדוחות.

## הפעלה

האתר סטטי ואינו דורש התקנה. מתוך תיקיית המאגר:

```sh
python3 -m http.server 8000 --directory dist
```

פתחו `http://localhost:8000` וטענו קובץ Excel. הקובץ מעובד בדפדפן בלבד. נתונים שנטענו נשמרים בזיכרון הדפדפן למשך הביקור, וייעלמו לאחר רענון הדף.

## פרטיות

המאגר אינו מכיל דוחות כספיים או נתוני לקוחות. אין להוסיף אליו קובצי רווח והפסד או קובצי Excel עם נתוני אמת. סביבת ההדגמה מתחילה ללא נתונים ומאפשרת העלאה מקומית בדפדפן.

ספריית JSZip הכלולה תחת `dist/jszip.min.js` מופצת ברישיון MIT או GPLv3; פרטי הקרדיט מופיעים בראש הקובץ.
